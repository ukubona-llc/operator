Okubala si Kulaba

Counting is not seeing. A five-stage routing operator, verified independently across four models, and older than all of them — the -bona root, carried from suffering to acknowledgment.

The claim is not that surprise happens. The claim is that Stage III decides whether Stage IV is ever invoked at all. Without the gate, there is no reason to pay for deliberation. Most of cognition — like most of computation — never crosses it.

Not a word for seeing at all, at first — a word for being subjected to. The raw event-stream arrives before it is parsed: high-volume, noisy, unfiltered, causally structured but not yet meaningfully segmented. Every architecture below begins here, in the layer that has no compression and no mercy.

II
Kubona / Okubala
Runyankore-Rukiga · to find — Luganda · to count

The stream becomes navigable. Fast, parallel, mostly unconscious — pattern recognition, associative memory, sensorimotor loops running below full awareness. This is the layer that keeps the world flowing without asking permission from anything slower. It is efficient because it is cheap, and it is cheap because it does not ask whether its model is still correct.

System 1 Fast Heuristic Local Dynamics Gradient Descent
Cognitive
Kahneman's System 1 — heuristics, emotional tagging, habit execution, running continuously and largely below awareness.
Computational
Stochastic gradient descent. The automatic, continuous, low-cost update — not Stage IV, which is what gets invoked when this stops being sufficient.
Dynamical
The Jacobian — first-order, local, linear approximation of how the system moves near where it already is.
III
Ivyabona
Kinyarwanda-adjacent · witnessing

Not "I understand." Not "I act." Only: the current model is inadequate. A witness does not explain — a witness notices. That is the whole job of Stage III, and it is a narrower job than "surprise" suggests. Surprise is the phenomenology. Witnessing is the operation: a thresholded routing decision, not an error signal.

Most cognition never visits IV. Most requests never reach the LLM. Most driving never becomes conscious. III is sparse by design — if every event triggered IV, the system would stall; if nothing did, it would never learn. III is the architecture's metabolic budget, spent only where the Jacobian's local information has stopped being sufficient.

IV
Ukubona / Okulaba
isiZulu · true seeing — Luganda · insight, inference

Expensive, effortful, and recruited selectively — invoked only after the gate has already decided the local model has failed. This is not gradient descent's job; it is what happens when gradient descent isn't enough and the system needs second-order information, search, restructuring, or a counterfactual it doesn't already have cached.

System 2 Global Optimization Second-Order / Restart
Cognitive
Deliberate reasoning — working memory, hypothetical simulation, overriding intuition, metacognition. Costly, so gated.
Computational
What's invoked when SGD fails: the Hessian, a global search, an architecture change — or abandoning local optimization outright.
Dynamical
Leaving the current basin. Second-order curvature information, evaluated only because the Jacobian alone could no longer explain the mismatch.
V
Sawubona
isiZulu · I see you — I have updated my model to include you

Not a decision. A write-back. Irreversible, embodied, and public: clicking Deploy, signing, publishing, boarding, pressing Send. The moment ambiguity resolves into directed behavior — and immediately becomes Stage I for everyone else downstream. "My thoughts be bloody, or be nothing worth" is not a celebration of violence; it is the exact moment simulation stops and action enters the world's event stream.

Commitment-Event Write-Back / Action Reality Changes
Cognitive
Goal-locking — vmPFC-mediated persistence, bistable perception collapsing to one interpretation, follow-through (and its shadow, escalation of commitment).
Computational
The commit. Parameters updated, deploy shipped, ledger appended — the change is now load-bearing for whatever reads it next.
Dynamical
Nietzsche's "writing with blood" — an update so costly it leaves scars, changing both the writer and the manifold they write on.
Editor's Note — Ukubona

Four models looked at the same five stages and three of them decorated the frame. Only one of them tested it — by noticing that III is not the surprise, but the decision about what to do with the surprise. That is a narrower claim, and narrower claims are the ones that can be wrong.

The root -bona does not mean "to see." It means to be brought into relation with something. It suffers it, finds it, witnesses it, understands it, and finally acknowledges it back — and only at that last step does the world itself change. Everything before Stage V is rehearsal. Okubala si Kulaba: counting is not seeing, and neither counting nor seeing is yet a commitment.
